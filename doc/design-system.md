# Summon 界面设计规范

版本：2026-09-08。适用于桌面聊天、Runtime 输入区、设置导航及相关上下文流程。

这次整理的目标是让对话更容易阅读、常用操作更容易找到，并在半屏窗口中保持完整可用。视觉以系统字体、中性底色和少量蓝色组成；通过间距、字重和表面层次表达关系。

## 参考与取舍

| 参考 | 本次借鉴 | 在 Summon 中的处理 |
| --- | --- | --- |
| [Chatbox](https://chatboxai.app/en)，含本机桌面版 | 直接的会话列表、清晰的输入区、就近的模型选择 | 输入区保留一个当前模型入口，Runtime、Provider、Model 在弹层中按需展开 |
| [Raycast AI](https://www.raycast.com/core-features/ai) 与 [AI Chat 文档](https://manual.raycast.com/ai/ai-chat) | 克制的导航、低对比辅助控件、明确的键盘操作 | 侧栏减少大块强调色，主色集中于选择、焦点和发送 |
| [Raycast Launcher](https://www.raycast.com)，含本机桌面版 | 平整的输入表面、小标题和轻量键盘提示栏 | Background Task 采用紧凑窗口、无独立边框的输入区及固定页脚 |
| [Msty Studio](https://msty.ai/products/studio/) | 工作区分层、复杂配置的分组表达 | 设置采用列表与详情、分组表单，避免把配置说明堆进聊天区 |

参考用于确定层级和交互方向。尺寸、组件结构和颜色以本仓库实际实现为准。

## 颜色

以下是默认浅色与炭灰深色主题。用户已有的蓝色 tint 仍使用原来的主题覆盖。

| 用途 / token | 浅色 | 深色 |
| --- | --- | --- |
| 窗口与导航底色 `--color-surface` | `#F7F8FA` | `#191B20` |
| 阅读区、输入框 `--color-surface-lowest` | `#FFFFFF` | `#1D1F24` |
| 轻量悬停背景 `--color-surface-low` | `#F0F2F5` | `#25282F` |
| 分组底色 `--color-surface-base` | `#ECEEF2` | `#2A2D35` |
| 选中会话 `--color-surface-high` | `#E5E8EE` | `#323640` |
| 正文 `--color-on-surface` | `#252831` | `#ECEEF3` |
| 辅助文字 `--color-on-surface-variant` | `#697180` | `#A1A9B8` |
| 边框 `--color-outline-variant` | `#DEE2E9` | `#343944` |
| 主色 / 焦点 `--color-primary` | `#3867D6` | `#83A6FF` |
| 主色容器 `--color-primary-container` | `#EDF2FC` | `#263552` |
| 容器内文字 `--color-on-primary-container` | `#315BB5` | `#B2C8FF` |

表面应相邻分层，避免给每个元素都加边框和阴影。发送按钮使用主色，普通会话选中用中性背景，设置分类选中用主色容器。

错误、成功、警告使用对应的语义 token 及配套 `on-*` 文字色。禁用按钮使用独立的灰色文字、背景和边框，不再对整个控件叠加半透明；占位符同样要能看清。

## 字体、间距与形状

默认字体为 `-apple-system, BlinkMacSystemFont, 'Segoe UI', 'Noto Sans', sans-serif`。不依赖在线字体下载。聊天的自定义字体设置继续生效；清空后继承系统字体。

| 层级 | 默认规格 |
| --- | --- |
| 欢迎标题 | 28 / 36px，600；聊天容器不超过 520px 时为 24 / 32px |
| 页面和分组标题 | 16–20px，600，沿用所在页面的共享组件 |
| 会话标题 | 14px，500 |
| 列表、选择器、主要辅助操作 | 13px，400–500 |
| 正文 | 默认 16px，行高 1.65；保留用户字号设置 |
| 输入文本 | 15 / 24px |
| 说明、分组日期、消息操作 | 12px；页脚信息 11px |

使用字重和位置建立层级，不让整段正文都变成粗体。中英文混排保持相同行高，长 URL、标识符和表格不能撑宽整个聊天页面。

间距优先采用 4、8、12、16、20、24、32px。注意本仓库 `--space-8` 是 **16px**，`--space-10` 是 **20px**，token 后缀不是像素数。

| 元素 | 圆角 / 尺寸 |
| --- | --- |
| 小按钮、分段选项 | 6px 圆角 |
| 导航行、选择器、图标按钮 | 8px 圆角 |
| 菜单、分组卡片 | 12px 圆角 |
| 聊天输入框 | 16px 圆角，20px 内边距，1px 边框；文本与操作栏间隔 16px |
| 常规图标 | 16px；重要入口可用 20px |
| 聊天工具按钮 | 32px 高，图标本身不充当点击区域 |
| 表单字段与按钮 | 40px 最小高度 |
| 会话行 | 普通模式至少 40px，紧凑模式至少 32px |

默认使用轻量 `--shadow-card`；浮层用 `--shadow-menu`。聊天输入框聚焦时只强调边框，不叠加外部光晕。新增动效保持短促，输入框过渡为 150ms，遵循 `prefers-reduced-motion`。

## 布局与响应式

主窗口由导航栏、会话侧栏、聊天区组成。窗口标题栏 40px，普通主窗口页脚 28px。高度依靠 flex 和 `min-height: 0` 分配，避免再写多套互相叠加的窗口高度减法。

会话侧栏默认 280px，沿用用户保存的拖动宽度；拖动值限制为 220–400px，实际显示还受 `min(30%, 340px)` 限制。窗口不超过 860px 时，侧栏最多 220px。聊天区始终保留收起侧栏的入口。

正文外层、输入框与 Agent 工具栏以 768px 为最大宽度，水平居中；聊天区两侧通常各留 24px。正文内部继续保留消息主题的缩进。欢迎区域最大 576px，不把空状态横向拉满宽屏。

输入框底部只保留上下文入口、Runtime 与模型入口和发送等必要操作。模型入口最多 320px，固定保留 Native / Hermes / OpenCode 名称，后接当前模型；空间不足时只省略模型名。完整连接、Provider、Model 通过 `title` 可查看。完整配置在最多 360px 宽的弹层中纵向排列，不再将三个选择器挤在输入框底部。

模型弹层优先位于入口上方，距入口 12px，距窗口边缘至少 16px；高度不足时使用窗口顶部空间并内部滚动。字段保持 40px 高；不能通过裁掉控件、移出屏幕或遮住发送按钮解决拥挤。

设置导航默认 220px，窄窗口为 184px。导航从顶部排列并可滚动。Connection、Agent、Workflow 的表单沿用共享容器，必要时将列表和详情改成上下排列。

紧凑任务窗口默认 640 × 260，最小 480 × 220。macOS 隐藏常规窗口标题栏和窗口按钮，任务标题区域可拖动；退出后恢复原窗口大小和按钮。其他平台保留系统窗口控制。任务正文左右各留 20px，底部提示栏至少 48px 高，输入内容独立滚动。长文本、截图和报错不能挤走底部操作。

## 组件规则

**会话侧栏。** 新建入口位于标题右侧；搜索常驻可见；Timeline / Folders 使用同一分段控件。批量操作只在选择模式出现。空列表与搜索无结果分别说明原因，不用空白区域代替反馈。长标题单行省略，悬停可看完整标题。

**欢迎区。** 一个安静的标识、一句标题、一句说明。快捷入口采用图标、标题、说明的纵向卡片；描述允许换行。更多快捷入口的展开与收起必须实际改变列表，并提供 `aria-expanded`。

**聊天输入框。** Native 与 Runtime 共用 `chat-composer`、`composer-actions` 和 `ChatConfiguration`。文本、上下文和模型入口属于一个完整输入区，不各自套一个大边框。默认文本区至少 64px 高；Runtime 输入超过 256px 后内部滚动。Agent 入口省去重复的可见标签，保留可访问名称。空白文本不允许发送，发送中保留停止操作。

**模型配置。** 默认显示 `Runtime · 模型名`，Runtime 使用较高字重且不收缩；外部 Runtime 未指定模型时显示 Runtime default。加载、未配置、错误和禁用状态均保留 Runtime 标识。连接自定义名称保留在悬停说明及弹层中。打开后焦点进入 Runtime 字段，保留 Provider / Model 的独立选择、加载、错误与 Retry。Esc 或关闭按钮返回入口焦点，外部点击、外部焦点、窗口缩放或输入区禁用时收起。重试引起字段更新时保持弹层打开。

**任务快捷窗口。** 顶部单行显示 `Workflow` 标签和工作流名称，名称为 16 / 24px、600 字重与正文色；不将名称弱化为灰色辅助文字。输入区无独立边框，页脚保持轻量；不重复显示 Background Task 说明。普通指令为 18 / 28px，选中文本为 15 / 24px，截图缩略图 64px。任务与 Agent 长名称单行省略，完整名称通过 `title` 获取。480px 时收起 Esc 的视觉提示，保留键盘取消行为及完整可访问说明；Enter 运行、Shift+Enter 换行、Esc 取消。

**消息。** 正文是页面视觉重点。辅助操作默认收起，鼠标悬停或键盘焦点进入时显示。复制、朗读、编辑等使用真正的按钮，操作栏可以换行。编辑时焦点进入文本框，取消后回到编辑按钮；空编辑内容不能提交。两种消息主题共用文字、焦点和语义颜色。

**菜单。** 使用主题表面、1px 边框、12px 圆角和轻量阴影；菜单项至少 32px 高，13px 文本、16px 图标。菜单触发器有名称、展开状态和键盘操作；关闭时不留下屏外可聚焦控件。

**设置表单。** 字段以任务分组，说明靠近对应字段。主操作、取消与删除有明确层级。保存/取消继续沿用现有行为；调整外观不能隐式覆盖模型、连接、可见性或工作流配置。

## 交互与状态

| 场景 | 必须呈现的行为 |
| --- | --- |
| 键盘 | 可交互元素有可访问名称和可见焦点；会话支持 Enter / Space；菜单不因原生 click 与 keydown 重复触发 |
| 中文输入 | 输入法候选确认不触发发送；Runtime 的 Shift+Enter 换行，Native 保留用户的发送快捷键偏好 |
| 未配置 | 明确显示 Provider / Model 或未配置提示，不显示无说明的空选项 |
| 加载 | 选择器显示加载文字并禁用，保持原位置和宽度分配 |
| 加载失败 | 就近显示错误与 Retry；重试可聚焦，不需要依赖悬停才能看到原因 |
| 长名称 | 视觉省略，完整文本仍可获取；不能挤走箭头或主操作 |
| 禁用 | 使用真实 `disabled`，保持文字和轮廓可辨认，移除可点击悬停反馈 |
| 成功 | 在相关操作附近显示简短反馈，避免让无关区域跳动 |
| 隐藏面板 | 不参与键盘与辅助技术导航；例如关闭的聊天设置面板使用 `inert` |

文案说明用户能做什么、当前发生什么及下一步操作。技术名称只保留在模型、连接等需要用户选择的位置。新增翻译按仓库约定先加入英文语言文件。

## 后续改动的验收

1. 先读对应组件和共享样式，查看当前 App；记录受影响入口和状态。
2. 检查宽窗口、800px 半屏窗口及断点两侧；涉及任务预览时检查真实紧凑窗口。
3. 检查深浅主题、长标题、长模型名称、中英文正文、空/加载/错误/禁用状态。
4. 实际操作搜索、下拉框、菜单、键盘焦点、编辑、取消及滚动。真实模型发送使用隔离数据验证。
5. 先运行 `npm run lint`，再运行相关单元测试。测试不能代替实际界面检查。
6. 恢复临时主题、窗口和草稿，核对已有配置，记录尚未验证的范围。
