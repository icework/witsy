## 代码与测试

`npm run lint` 通过 ESLint、Vue / TypeScript 和 Stylelint。相关 **20 个测试文件、480 项测试全部通过**，覆盖聊天布局与侧栏、输入框、菜单、消息、Runtime / 模型选择、设置与配置表单。

本机 Node 的实验性 Web Storage 会与测试环境冲突，因此测试命令临时使用 `NODE_OPTIONS=--no-experimental-webstorage`。没有修改项目的运行环境配置。

重点新增或修正的行为检查：空白消息禁用发送、Runtime 中文输入法确认不发送、Shift+Enter 换行、欢迎快捷入口展开、清空自定义字体恢复继承。设置测试移除了“字段必须恰好有 10 个”的陈旧结构断言，保留了实际字段修改与保存的断言。

另外单独运行 `tests/unit/renderer/components/chat_view.test.ts`：14 项通过、10 项失败。在独立工作树中重建“开始本次 UI 工作前的 HEAD + 用户已有未提交修改”后，复现了同样的 10 个失败。失败涉及旧测试中的空 assistant 初始化及 `mock` 默认 provider / model 预期。本次没有把这组测试标为通过，也没有更改相应业务行为。

## 追加调整：输入区与 Quick Launcher

用户反馈输入框拥挤，并希望 Background Task 接近 Raycast Launcher 的简洁程度。以下记录是对上面首轮验收的追加，尺寸与组件规则以更新后的设计规范为准。

- Native 与 Runtime 的三个并排选择器合并为一个当前模型入口；完整配置在 360px 弹层中纵向展开。输入区内边距增至 20px，文本区最小高度增至 64px，操作栏间隔 16px，去掉聚焦外光晕和重复的 Agent 标签。
- Quick Launcher 默认改为 640 × 260，最小 480 × 220；macOS 隐藏常规标题栏与窗口按钮，保留任务标题拖动区。去掉重复说明与输入框外的大边框，页脚使用 Agent 名称和轻量快捷键提示。
- 长任务名、模型名和 Agent 名称省略显示；模型完整名称可通过弹层查看。修正辅助功能点击和焦点转移的收起行为；目录重试导致按钮更新时不会误关弹层。

| 检查方式 | 覆盖内容 | 结果 |
| --- | --- | --- |
| 原生 Electron，800 × 740，深浅色 | Native 输入区、模型弹层、外部点击、Runtime 切换 | 输入与操作分开，弹层字段完整，关闭后可继续输入 |
| 原生 Electron，640 × 260 与手动缩至 480 × 220 | 空白任务、长中文输入、滚动、Esc 取消、窗口控制恢复 | 输入区独立滚动，页脚固定；取消后恢复 800 × 740 和窗口按钮 |
| 隔离真实组件，1280 × 820 与 800 × 740 | 长模型名、Native / Runtime、加载、失败 / Retry、未配置、深浅色 | 弹层不越出窗口，错误可重试，返回输入区自动收起 |
| 隔离真实组件，640 × 260 与 480 × 220 任务区 | 截图、选中文本、长任务与 Agent 名称、错误、禁用、Shift+Enter 与 Enter | 文本与错误不挤走页脚；长名称省略；隔离提交成功 |

## 追加调整：常驻 Runtime 与 Workflow 名称

根据用户反馈，模型入口现在直接显示 `Native / Hermes / OpenCode · 模型名`。Runtime 名称不收缩，加载和失败时同样常驻；自定义连接名称仍可通过悬停和配置弹层查看。Quick Launcher 顶部增加 Workflow 标签，工作流名称改为 16px、600 字重和正文色。

实际检查原生 800 × 740 的 Native / Hermes 切换、640 × 260 与 480 × 220 的任务名称及 Esc 恢复。隔离真实组件检查 1280 × 820、720 × 740 的长模型名、深浅主题及加载 / 失败状态，并检查 480 × 220 任务区中的长 Workflow 名称、文本与截图预览。Runtime 完整可见，长模型和工作流名称正常省略，页脚保持可见。

`npm run lint` 通过，相关 **10 个测试文件、252 项测试全部通过**。新增断言覆盖 Native 标识、Hermes / OpenCode 在目录加载前后及失败时的标识，以及任务标题与可访问名称。未发送真实模型任务；原生 App 留在 Native 空白新会话，窗口恢复 800 × 740。
